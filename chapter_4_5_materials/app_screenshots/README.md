# Streamlit application screenshots

These screenshots document the locally rendered Catfish Attribute Estimator interface for later use in Chapters 4 and 5.

- `01_app_desktop.png` — standard desktop viewport.
- `02_app_full_page.png` — full application page, including instructions, inputs, disclaimer, and footer.
- `03_fingerling_prediction_result.png` — genuine fingerling model output.
- `04_juvenile_prediction_result.png` — genuine juvenile model output.
- `05_adult_prediction_result.png` — genuine adult model output, including the physical-plausibility warning produced by the interface.
- `sample_inputs/` — reference image crops recovered from the notebook EDA figure.
- `prediction_results.json` — machine-readable values displayed in the three result screenshots.

The screenshots were captured from `http://127.0.0.1:8501/` using the repository's local Streamlit environment.
The result screenshots were rendered through the application's own result components using outputs generated by the repository's trained model.
